Кеңейтім әлі қосылмаған

Бұл бет компьютеріңіздегі Chrome кеңейтімі арқылы жұмыс істейді. Бір рет орнатасыз (3 минут):
  1. Төмендегі батырма — бот файл мен нұсқаулықты чатқа жібереді.
  2. Компьютерде Chrome: chrome://extensions → Developer mode → Load unpacked → «meet-tekseru» папкасы.
  3. Ашылған бетте «Telegram-ды қосу» → ботта Start.
